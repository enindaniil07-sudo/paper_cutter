# CLEAN_TABLO_FW — Black Pill F411CE

Прошивка для табло **CLEAN_TABLO** + энкодер **Autonics E40S6-1000-3-T-24**.

## Железо

| Сигнал | Пин | Примечание |
|--------|-----|------------|
| Энкодер A | **PB0** | rising, через level-shift ≤ 3.3 V |
| Энкодер B | **PB1** | направление: считаем только вперёд |
| LED | PC13 | мигает (быстрее в Run) |
| DWIN UART | PA2/PA3 (USART2) | 115200 8N1, **CRC ON** (как в T5LCFG) |

Datasheet энкодера: **1000 импульсов / оборот** по каналу A.  
Колесо на валу: **Ø 8 см** → длина окружности `C = π × 0.08 ≈ 0.251327 м/об`.

## Формулы

На каждый rising A (и B = «вперёд»):

```
1 импульс → 0.251327 мм пути   (C / 1000)
```

Накопленный путь (целые метры на экране):

```
пройдено [м] = N × C / PPR = N × π × 0.08 / 1000
```

За окно Δt (≈40 мс, измеряется в µs):

```
об/мин  = ΔN × 60 000 000 / (PPR × Δt_us)   → EMA(α=0.25)
м/с×0.01 = ΔN × NM_PER_PULSE / (Δt_us × 10) → EMA
```

На DWIN:
- **VP 6000** — задано, целые метры  
- **VP 6010** — осталось, целые метры (`ЗАДАНО − floor(пройдено)`)  
- **VP 6030** — прогресс 0…100 % (**Process Bar 0x5A23**)  
- **VP 6020** — скорость ×0.01 м/с (например 125 = 1.25 м/с)  
- **VP 6024** — об/мин  
- **VP 6052** — СБРОС (BitButton)

## Сценарий

1. Тап **ЗАДАНО** (Variable Data Input) → стр. 10 → **OK** → VP 6000  
2. **СТАРТ** → режим Run, счёт пути/скорости/об/мин  
3. Когда `пройдено ≥ задано` → Stopped (скорость обнуляется)  
4. **СТОП** — стоп скорости  
5. **СБРОС** — обнуляет задано, осталось, прогресс, скорость, RPM, энкодер  
6. **Реверс** (B ≠ уровень «вперёд» на rising A) → стр. **11** «ОШИБКА ВРАЩЕНИЯ»; путь назад не считается. Снять: **ИСПРАВИТЬ** или **СБРОС**.

Если ошибка появляется при «правильном» направлении — в `config.h` смени `ENC_FORWARD_B_LEVEL` с `LOW` на `HIGH`.

## Прошивка

Открой `CLEAN_TABLO_FW.ino` в Arduino IDE (плата STM32F411CE Black Pill) и залей.

Экран: залить `DWIN\CLEAN_TABLO\DWIN_SET` (слот фона **32.icl**).
