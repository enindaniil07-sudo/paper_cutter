# CLEAN_TABLO_FW — Black Pill F411CE

Прошивка для табло **CLEAN_TABLO** + энкодер **Autonics E40S6-1000-3-T-24**.

## Железо

| Сигнал | Пин | Примечание |
|--------|-----|------------|
| Энкодер A | **PA0** | TIM2_CH1 (перепаять с PB0) |
| Энкодер B | **PA1** | TIM2_CH2 (перепаять с PB1) |
| Реле тормоза | **PB0** | HIGH = вкл.; импульсы из настроек ШИМ 1/0 |
| LED | PC13 | мигает (быстрее в Run) |
| DWIN UART | PA2/PA3 (USART2) | 115200 8N1, **CRC ON** |
| Дальномер (ESP32-C3) | **PA10** RX / PA9 TX (USART1) | 115200 8N1, строки `мм\n` / `NA\n` от `c3_receiver.ino` |

## Дальномер (ESP32-S3 → ESP32-C3 → Black Pill)

GL-R01 на **ESP32-S3-Zero** (`ESP32/s3_zero_sender`) → ESP-NOW → **ESP32-C3** (`ESP32/c3_receiver`) → USART1.

| ESP32-C3 | Black Pill | Примечание |
|---|---|---|
| GPIO21 (TX) | **PA10** (USART1_RX) | по нему идут миллиметры |
| GPIO20 (RX) | PA9 (USART1_TX) | резерв, можно не подключать |
| GND | GND | общая земля |
| 5V | 5V | питать от 5 В, не от 3V3 (пики Wi-Fi) |

`USE_USART1` в `config.h` должен быть `0` (DWIN на USART2), PA11/PA12 — USB, не трогать.

Настройка **ПУСТОЙ РУЛОН** (стр. 17, VP **6098**, мм): рулон разматывается, расстояние от датчика до бумаги растёт;
когда в Run `расстояние ≥ настройка` — реле включается тем же ШИМ (6094/6096), что и зона «торм. м», и держится до остановки вала.
`0` — выключено. Нет данных от C3 дольше `RANGE_TIMEOUT_MS` (1 с) или `NA` — по дальномеру не тормозим, зона по метрам работает как раньше.
После остановки по дальномеру — как после СТОП: реле отпущено, счёт продолжается, повторно не тормозит до СБРОС / нового ЗАДАНО.

Счёт импульсов — **TIM2** (32-бит CNT), без ISR на каждый фронт.  
MCU раз в цикл читает CNT и флаг **UIF**; при overflow CNT сбрасывается, путь на экране сохраняется (soft `g_nm`).

Обрыв канала A/B (стр. **15**): сэмпл PA0/PA1 через GPIO IDR при AF TIM2; оба канала должны сначала «доказать жизнь», затем один молчит ≥2 с при живом втором.

Datasheet энкодера: **1000 импульсов / оборот** по каналу A.  
TIM Encoder mode 2: **2000 TIM-тиков / оборот**.  
Колесо: **Ø 8 см**.

## Формулы

На каждый rising A (и B = «вперёд»):

```
раньше (GPIO ISR): 1 импульс A → 0.251327 мм
сейчас (TIM2 mode2): 2 тика TIM / период A → 0.125664 мм / тик
```

За окно Δt (≈40 мс, измеряется в µs):

```
об/мин  = ΔN_tim × 60 000 000 / (2000 × Δt_us)   → EMA
м/с×0.01 = ΔN_tim × NM_PER_COUNT / (Δt_us × 10) → EMA
```

При UIF (переполнение TIM2): тики учитываются в soft-пути, **CNT:=0**, дисплей не обнуляется.

На DWIN:
- **VP 6000** — задано, целые метры  
- **VP 6010** — осталось, целые метры со знаком (`ЗАДАНО − floor(пройдено)`; после переезда — минус)  
- **VP 6030** — прогресс 0…100 % (**Process Bar 0x5A23**)  
- **VP 6020** — обороты, целые об/мин (левая половина табло)  
- **VP 6024** — расстояние дальномера, мм (правая половина; 0 пока замера нет, при обрыве остаётся последний)  
- **VP 6040** — бейдж ошибки: `0` скрыто / `1` ЭНК. / `2` ТОРМ. (IconShow `28.icl`)  
- **VP 6052** — СБРОС (BitButton)  
- **VP 6090 / 6094 / 6096 / 6098** — настройки: торм. м / ШИМ 1 мс / ШИМ 0 мс / пустой рулон мм  

Реле (**PB0**): в Run, когда `осталось ≤ торм.м` **или** `дальномер ≥ пустой рулон`, выход чередует HIGH `6094` мс и LOW `6096` мс.  
Вне зоны / Stop / ошибка — LOW. `on=0` — выкл.; `off=0` при `on>0` — постоянный HIGH в зоне.

## Сценарий

1. Тап **ЗАДАНО** (Variable Data Input) → стр. 10 → **OK** → VP 6000  
2. Вал вручную → первые импульсы энкодера → Run (если ЗАДАНО=0 → стр. **13**)  
3. Когда `пройдено ≥ задано` → Stopped (скорость обнуляется)  
4. **СТОП** — пауза **без тормоза**; задание не закрывается. После СТОП или после того как автотормоз уже остановил вал — реле MCU **не** включает (его включают снаружи); остаётся только счёт до конца. Конец задания — когда пройдено ≥ задано (или **СБРОС**).  
5. **СБРОС** — обнуляет задано, осталось, прогресс, скорость, RPM, энкодер  
6. Шестерёнка (BitButton VP **6055**, Pic_Next=**17**) → настройки тормоза и дальномера; доступны **в любой момент** (до, во время и после задания). Тап строки → стр. **18**. НАЗАД: VP **6056**. Счёт и прогресс не останавливаются. MCU **не** шлёт `dwinSetPage(17)`.  
7. Ошибки — **только бейдж** в окошке под шестерёнкой на главном экране (IconShow **VP 6040**, `28.icl`). Страницы не переключаются, кнопки OK нет, FSM-состояние (Run/Stopped) не меняется:

   | VP 6040 | Бейдж | Когда поднимается | Когда снимается сам |
   |---|---|---|---|
   | `0` | — | | |
   | `1` | **! ЭНК.** | Run, уже были импульсы, затем тишина ≥ `ENC_NO_SIGNAL_MS` (4 с) | снова пошли импульсы энкодера |
   | `2` | **! ТОРМ.** | зона тормоза, за `BRAKE_EFF_PERIOD_MS` (3 с) скорость не упала ≥ `BRAKE_EFF_MIN_DROP_CMS` / 10 % | скорость пошла вниз (следующий период) или вал встал |

   Бейдж держится минимум `ERR_BADGE_MIN_MS` (1.5 с), чтобы не мигал. **СТОП** и **СБРОС** снимают любой бейдж. При ТОРМ. ШИМ реле продолжает работать, пока вал крутится; при ЭНК. реле выключается.

Если ошибка при «правильном» вращении — поменяй местами A/B на PA0/PA1 (или инвертируй полярность входа в `enc_tim2.cpp`: `CC1P`/`CC2P`).

## Страницы HMI / show

| Стр. | Назначение |
|------|------------|
| 0 | Главный экран (+ бейдж ошибки VP 6040) |
| 10 | Клавиатура ЗАДАНО |
| 16 | Пустая (заглушка) |
| **17** | Список настроек (ArtText idle-цифры + VarInput→18) |
| **18** | Клавиатура правок настроек |

**Show:** стр. 17 — ArtText из DGUS Generate (патч сохраняет); 16/18 пустые. Python не создаёт ArtText на 16–18. Подробнее: `DWIN/CLEAN_TABLO/DGUS_SHOW_WORKFLOW.md`.

Значения настроек MCU держит в RAM и пишет в **EEPROM** при изменении; при старте загружает и пушит на панель.

Открой `CLEAN_TABLO_FW.ino` в Arduino IDE (плата STM32F411CE Black Pill) и залей.
